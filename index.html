iPhone Duo 壁纸测试

新：在 iPhone Duo 外形里预览（合上 / 打开 / 空版 / 图标）→

点一张图打开大图 → 长按 → 「添加到照片」，再到 设置 → 墙纸 里设置。

先测这张（最重要）

把下面的编号图设成壁纸，铺满内屏，然后合上手机，看外屏显示的是几号色块。

  1. 合上时外屏显示几号到几号？（例如 1–3 = 左边，3–4 = 中间）
  2. 墙纸设置里能不能给外屏、内屏分别选不同的图？
  3. 时钟在外屏、内屏的什么位置？挡住了几号？
  4. 拍两张照片：合上一张，打开一张。
保存壁纸到相册
  1. 点图片下面的「下载原图」，或者点图片打开大图。
  2. 在大图上长按 → 选「添加到照片」（如果弹出「下载」，就去 文件 App → 下载 里打开再存到照片）。
  3. 设置 → 墙纸 → 添加新墙纸 → 照片，选刚存的图。
再测壁纸（新版每套都是两张）
  1. 墙纸设置里如果能给外屏、内屏分别选图：外屏用「外屏（合上）」，内屏用「内屏（打开）」。合上、打开各拍一张。
  2. 一图三屏（先试这个）：下载「一图三屏」存到照片 → 设置壁纸选它 → 合上时把下面左边那张放大铺满外屏 → 展开横屏，把上面那张铺满内屏 → 转成竖屏，把下面右边那张铺满。三个状态都调好再保存。别露出旁边的图。
  3. 如果只能设一张：用「内屏（打开）」，然后合上，看外屏显示的是哪一部分，拍下来。
  4. 再试「内屏空版」，看图标放上去挡不挡东西、时钟在哪里。
  5. 每套建议先试：可口可乐冰柜、香奈儿 CF 包、Rimowa。
